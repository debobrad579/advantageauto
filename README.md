# Advantage Auto Website

A modern, responsive website for Advantage Auto, a professional automotive repair shop located in Brantford.

## 🌐 Live Site

Visit [advantageauto.ca](https://www.advantageauto.ca)

## 📄 Pages

- **/**: Hours, contact information, and shop image
- **/who-we-are**: Details about the business
- **/staff**: A list of staff members
- **/services-offered**: A list of services offered
- **/buying-a-used-car**: Tips to consider when buying a used car
- **/vehicles-to-avoid**: A list of vehicles that are not recommended
- **/appointment-request**: A form that emails an appointment request to the shop
